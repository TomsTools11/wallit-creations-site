# Wallit Creations

Static single-page site. `index.html` is self-contained (all images, fonts,
and scripts are embedded and unpacked client-side), so no build step is
required.

## Deploy on Vercel

1. Go to https://vercel.com/new and import this GitHub repository.
2. Framework preset: **Other** (no build command, no output directory needed).
3. Deploy.

Vercel will serve `index.html` as a static file with no configuration beyond
what's already in `vercel.json`.
